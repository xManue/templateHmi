# Machine View Controls Popup

Template collegato direttamente alla pagina `machine-view` del pannello
`can-line-operator`. Si apre cliccando una zona macchina.

Il selettore contiene i nomi fittizi delle parti della linea. I comandi Start,
Stop, Reset, Lower, Advance e il selettore Manual/Auto espongono callback ma non
inviano azioni reali a un PLC.
