# Machine Counters

Pagina HMI collegata alla voce `Counter Machine` del popup `Main` di `operator-shell`.

Contiene contatori del metal detector, contatori bundle, diagnostica dell'ultimo scarto e dettaglio delle cause di rifiuto. Tutti i valori in `src/templateData.js` sono dati fittizi di anteprima e vengono sostituiti durante la creazione del pannello operatore.

## Avvio autonomo

```powershell
pnpm install
pnpm run dev:machine-counters
```
