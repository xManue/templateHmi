# Operator Shell Alarms Menu

Template collegato alla voce `Alarms` di `operator-shell`.

Entrambe le voci aprono lo stesso template `alarm-list`:

- `Alarms` passa `mode="alarms"`;
- `History` passa `mode="history"`.

Le etichette sono variabili di anteprima in `src/templateData.js` e vengono personalizzate durante la creazione del pannello.
