# Operator Shell Main Menu

Template collegato direttamente a `operator-shell`. Si apre cliccando la voce `Main` della barra laterale e riproduce il popup dello screenshot di riferimento.

Il componente `src/MainMenuPopupTemplate.jsx` riceve `items`, `open` e `onSelect`. Le voci e le icone dell'anteprima sono definite in `src/templateData.js`.

Questo template non ha un'app Vite separata: viene compilato e visualizzato attraverso l'anteprima del template padre.
